使用说明与边界
  • 输入上限为 100 万字符、30,000 个节点、80 层嵌套。仅支持严格 JSON，不自动修复、不支持 JSON5。
  • 使用 JavaScript 数值语义：拒绝不安全的大整数和溢出；高精度小数请使用字符串。重复键遵循 JSON.parse，后者覆盖前者。
  • 键名排序递归处理对象，数组不重排；整数形式的键仍遵循 JavaScript 的数字键顺序。
  • CSV 接受对象数组，嵌套值保存为 JSON 字符串，并为可能触发电子表格公式的单元格加单引号。
  • TypeScript 和 Schema 根据当前样本推断，不能替代完整业务契约；Schema 不代表已执行数据校验。
  • 不上传、不自动保存、不读取剪贴板；刷新或离开页面将丢失输入，请自行下载结果。
